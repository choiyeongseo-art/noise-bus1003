# NØISE · BUS 1003

부산의 밤을 배경으로 한 채팅형 인터랙티브 스토리 + 아이돌 육성 웹 게임 미리보기입니다.

## 플레이

https://choiyeongseo-art.github.io/noise-bus1003/

- 1챕터 15씬과 선택지, 주파수에 따른 엔딩
- 제공된 프로필 사진과 웹용 3D 녹스 모델
- 훈련, 거리 라이브, 심야 파견, 팬레터, 민원 대응
- Supabase 이메일·비밀번호 회원가입 및 회원별 클라우드 저장
- 비로그인 미리보기는 시간 ×60, 정식 계정과 별도 저장
- 2챕터 이후, 벤·엘른 영입 및 쇼케이스는 업데이트 예정

## 로컬 실행

Node.js 24와 pnpm 11.25.0을 사용합니다.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

GitHub Actions가 main 브랜치의 변경을 GitHub Pages에 자동 배포합니다.

## 데이터 저장

`lib/supabase.ts`에는 브라우저용 공개 키만 들어 있습니다. 서비스 역할 키나 데이터베이스 비밀번호는 포함하지 않습니다. 회원별 저장 권한은 `supabase/schema.sql`의 RLS로 제한하며, 저장 버전 충돌을 검사합니다.

현재 미리보기는 이메일 인증 메일 없이 가입합니다. 공개 가입 전에 메일 인증이 필요하다면 SMTP를 연결하고 Supabase의 Confirm email을 켜세요.

## 에셋

캐릭터 이미지, 3D 모델, 음원은 프로젝트 제공 자료에 기반합니다. 저장소의 공개는 에셋의 자유로운 재사용을 허용하는 라이선스 부여를 의미하지 않습니다.
